# Navbar Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a global top navigation bar with the free design.md brand, "powered by Agent Native" attribution, Quality and agent-native.com links, and the account chip.

**Architecture:** New `NavBar` component added to `root.tsx` so it renders on all routes. AccountChip and the Quality link are removed from the inline header in `_index.tsx` — they live in the nav from now on.

**Tech Stack:** React, React Router `<Link>`, Tailwind CSS, shadcn tokens, existing `AccountChip` component.
